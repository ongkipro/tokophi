## Akun dan toko

| | |
|---|---|
| Nama toko | 3–60 karakter |
| Kata sandi | Minimal 8 karakter |
| Gagal masuk berturut-turut | Dikunci 15 menit setelah terlalu banyak percobaan |
| Tinjauan toko baru | Biasanya 1×24 jam |
| Uji coba gratis | 3 hari sejak mendaftar |
| Masa tenggang langganan | 3 hari setelah jatuh tempo |
| Deskripsi singkat toko | Maksimal 160 karakter |

## Produk

| | |
|---|---|
| Ukuran foto | Maksimal 2 MB per foto, JPG/PNG/WebP/SVG, dikonversi ke WebP |
| Jenis varian | Maksimal 2 per produk (misalnya Warna dan Ukuran) |
| Berat kosong | Ongkir dihitung dengan asumsi 500 g |
| Berat volumetrik | P × L × T (cm) ÷ 6.000 = kg |

## Pesanan dan pengiriman

| | |
|---|---|
| Pesanan prepaid belum dibayar | Batal otomatis setelah 24 jam |
| Pengiriman Massal | Maksimal 50 pesanan sekali jalan |
| Pengecekan resi otomatis | Setiap 15 menit |
| Jadwal jemput kurir | Besok pukul 10.00 WIB |
| Ukuran label | 100 × 150 mm (printer thermal) |
| Pembatalan pengiriman | Hanya sebelum kurir menjemput. Bisa butuh hingga 48 jam untuk diproses |
| COD | SPX, 6 provinsi di Jawa, total pesanan maksimal Rp2.000.000 |

## Uang

| | |
|---|---|
| Minimum penarikan | Rp200.000 |
| Biaya penarikan | Gratis |
| Waktu proses penarikan | 1–2 hari kerja |
