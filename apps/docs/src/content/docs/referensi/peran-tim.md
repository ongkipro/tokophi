Pemilik toko mengundang anggota dari **Pengaturan → Pengguna → Undang pengguna**. Lihat [Masuk dan amankan akun](/mulai/amankan-akun/#beri-akses-ke-tim).

| Peran | Bisa mengubah |
|---|---|
| **Pemilik** | Semuanya, termasuk pengaturan toko, rekening, langganan, penarikan saldo, dan HTML landing page. |
| **Admin** | Semua kecuali pengaturan toko, integrasi, dan HTML landing page. |
| **Staf** | Produk, diskon, konten, pesanan, pelanggan, CRM, media, dan obrolan. Tidak bisa menghapus produk atau mengubah stok dan pembelian. |
| **Staf Gudang** | Stok dan pesanan pembelian saja. |
| **Advertiser** | Diskon, konten, media, dan integrasi pixel iklan. |
| **Customer Service** | Pesanan, pelanggan, CRM, dan obrolan. |

Semua peran bisa membuka menu **Bantuan**.

:::tip
Beri peran yang paling sempit tapi cukup. Pemilik toko tidak bisa diubah perannya atau dikeluarkan.
:::
