## Langganan

Satu paket bernama **TokoΦ** dengan semua fitur terbuka. Tidak ada batas jumlah produk.

| | Harga |
|---|---|
| Uji coba | Gratis 3 hari sejak mendaftar |
| Bulan pertama | Rp50.000 |
| Bulanan berikutnya | Rp275.000 per bulan |
| Tahunan | Rp2.700.000 per tahun (setara Rp225.000 per bulan) |

- Kalau Anda langsung membayar tahunan setelah uji coba, pembayaran pertama itu berlaku **13 bulan**.
- Harga di atas adalah DPP (sebelum pajak). Rincian pajak, bila ada, tercantum di faktur.
- Bayar dari **Akun → Langganan → Lanjutkan pembayaran**. Hanya pemilik toko yang bisa membayar. Langganan aktif otomatis setelah pembayaran diterima.
- Setelah jatuh tempo ada **masa tenggang 3 hari**. Lewat dari itu Dashboard Seller menjadi baca-saja sampai tagihan dibayar, tetapi toko Anda tetap online untuk pembeli.

## Biaya yang dibayar pembeli

Biaya transaksi ditambahkan ke total belanja pembeli. Anda tidak menanggungnya.

| Metode | Biaya |
|---|---|
| QRIS | 0,7% dari harga barang |
| Virtual Account BNI, BRI, Mandiri, Permata | Rp3.000 per transaksi |
| Virtual Account BCA | Rp6.500 per transaksi |
| COD (bayar di tempat) | 3% dari harga barang + ongkir, minimal Rp2.500, ditambah PPN 11% atas biaya itu |

Ongkir juga dibayar pembeli sesuai tarif layanan kurir yang dipilihnya.

:::note[Ongkir dengan kurir pilihan Anda]
Kalau Anda memesan layanan yang **lebih mahal** dari yang dibayar pembeli (lewat **Cek Ongkir** di detail pesanan), selisihnya dipotong dari hasil pesanan atau dari saldo Anda. Memesan lewat **Pengiriman Massal** selalu memakai layanan yang dibayar pembeli, jadi tidak ada selisih.
:::

## Yang masuk ke saldo Anda

Harga barang (termasuk PPN barang bila Anda mengaktifkannya). Ongkir dan biaya transaksi tidak masuk ke saldo.

## Penarikan saldo

| | |
|---|---|
| Minimum penarikan | Rp200.000 |
| Biaya penarikan | Gratis |
| Waktu proses | 1–2 hari kerja, diperiksa tim TokoΦ |
| Siapa yang bisa menarik | Pemilik toko |
| Syarat | Rekening sudah diisi di **Pengaturan → Rekening** |

Penarikan yang sudah diajukan tidak bisa dibatalkan.
