Bab ini berisi panduan per tugas untuk menu **Tema**, **Navigasi**, **Halaman**, dan **Blog** di grup **Toko Online**, serta **Pengaturan → Domain**. Setiap artikel bisa dibaca terpisah. Kalau Anda baru mulai, ikuti dulu langkah singkat [Rapikan tampilan toko](/mulai/tampilan-toko/).

- [Susun beranda, kategori, dan produk dengan Store Builder](/tampilan/susun-halaman/): template per jenis halaman, template default, bagian yang tersedia, serta font dan warna.
- [Atur menu header dan footer](/tampilan/menu-navigasi/): menu mana yang tampil di mana, item, dan sub-menu.
- [Buat halaman Tentang Kami, Kebijakan, dan lainnya](/tampilan/halaman-statis/): halaman statis dan cara menautkannya.
- [Tulis artikel blog](/tampilan/artikel-blog/): artikel untuk halaman Jurnal toko.
- [Pasang domain sendiri](/tampilan/domain-sendiri/): hubungkan domain milik Anda dan jadikan alamat utama toko.
