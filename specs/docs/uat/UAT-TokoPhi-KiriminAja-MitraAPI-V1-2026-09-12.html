Catatan Khusus Label
  • Label dicetak jelas 100×150 mm (thermal) dan ditempel aman pada paket.
  • Barcode AWB dapat discan (Code 128 asli); order reference dicetak sebagai teks, bukan barcode.
  • JNE Drop-Off (CASHLESS COD/Non-COD) belum berlaku — integrasi hanya memakai pickup request.
  • SPX / J&T Cargo: sorting/routing code akan ditambahkan begitu nilainya diterima dari PIC KiriminAja.
Permintaan ke KiriminAja (action items)
  1. Konfirmasi drift harga quote↔booking sandbox di atas 1 kg: booking multi-kg pada harga quote-nya sendiri ditolak "Ongkir tidak sesuai" (9 kurir), sedangkan parcel 2 kg diterima pada harga 1 kg (OID 5758-E1kgprice150). Integrasi kami mengirim angka quote KiriminAja sendiri. Mohon konfirmasi produksi tidak berperilaku sama.
  2. Penerbitan AWB sandbox untuk 8 OID di atas agar skenario Tracking (riwayat) dan Cancel/Void dapat dieksekusi.
  3. Nilai sorting code per kurir (khususnya SPX 2 kolom) dan ketentuan logo kurir pada label.
  4. Kontrak autentikasi webhook: dokumentasi mendeklarasikan event tanpa security scheme; receiver kami memerlukan Authorization: Bearer {api_key}. Mohon konfirmasi header yang dikirim.
  5. Konfirmasi status akun terkait KA Credit (endpoint credit/balance tidak dilayani untuk akun ini).
