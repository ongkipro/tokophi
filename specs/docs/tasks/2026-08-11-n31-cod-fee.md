# N31 — show the COD fee KiriminAja charges (2026-08-11)

**Branch:** `feat/n31-cod-fee` · **base:** `origin/main` @ `60b26a4` · **size:** S

Every `shipping_price` rate carries `setting.cod_fee` (a STRING fraction already divided by 100 —
`"0.03"` = 3%), `setting.minimum_cod_fee` (IDR floor, string) and `setting.cod_fee_amount` (IDR,
vendor-computed from item value + shipping cost + insurance). Nothing read them; a merchant selling
COD saw the ongkir but never the fee deducted from their payout. Shape verified against the captured
vendor doc (`~/Documents/kiriminaja/documents/04-pricing/01-express.md`) and then against the live
sandbox in a browser.
