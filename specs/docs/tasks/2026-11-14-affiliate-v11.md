## Decisions the owner may want to revisit

1. **Rank floor `admin`** for the Super Admin Affiliate screen and both actions (`AFFILIATE_ACCOUNT_MIN_RANK`).
   Not `owner`: an affiliate account is not a merchant's shop and moves no money (bank details live on each
   store's row, written by the seller; the affiliate cannot edit them). Not `support`: "cannot touch credentials".
2. **Funnel is ref-only** — no "Kode affiliate" field on `/lp` / `/promo`. A buyer who only has a typed code must
   use the cart checkout.
3. **CSV date = order date (WIB)**, not commission paid date. The tax note ("Pemotongan pajak atas komisi (PPh)
   menjadi tanggung jawab toko") is on screen, not inside the file, so the CSV stays machine-readable.
4. **No store-side audit row** for the affiliate edit — consistent with every other Seller affiliate action (the
   Seller panel has no affiliate audit log); impersonated operators are still logged by `requireCapability`.
5. Name validation on edit uses `nameError` (no digits), the affiliate app's own sign-up rule; an old
   Seller-added name with digits must be corrected when the row is next edited.
