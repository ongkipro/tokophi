## The compressed lessons — every mistake this stretch had ONE of two shapes

**A. Inferring state instead of observing it.** Deploy "broken" (never read the webhook reply) ·
"no .id anywhere" (never curled) · "priority 1 free" (formalin-web was there) · SEC-4 "bad selectors"
(account didn't exist) · "merchant DNS correct" (trusted `verified_at`) · ".com is the target"
(trusted a stale doc over the code) · "DNS empty" (botched dig syntax + caches). **Run the one command
that would prove it works, against the authoritative source.**

**B. A check that can't fail for the right reason.** The `tail`-swallowed exit status · the test that
threw on `DATABASE_URL` before asserting · the validator that ran but didn't gate (twice) · deleting a
remote branch after a FAILED merge. **Gate on `$?`, mutation-test every guard, and never clean up
until the step you're cleaning after has provably succeeded.**

And the pair that closes the loop: **the same bytes can be right or wrong** — apex A records identical
to `cname.tokophi.cc`'s were the copied-IP mistake on beautyinu and correct flattening on taniniaga.
When bytes can't distinguish, find the party whose verdict can (Cloudflare's), and defer to it.

⚠️ When correcting a record, the note must keep naming the WRONG value — never sweep a history file.
And validate by **content** (page title = right store), not by status code: a 200 serving the wrong
catalogue is the failure mode that actually shipped, briefly, on 2026-08-11.
